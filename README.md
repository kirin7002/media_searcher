# Media Searcher

网盘资源搜索器项目，用于聚合多个来源的公开分享索引，统一展示资源标题、网盘类型、分享链接、提取码与来源信息。

## 当前进度

已完成首轮数据来源与接口调研，搜索器代码尚未实现。

- [来源调研与接口验证记录](docs/SOURCES.md)
- 已实测盘搜索 API 返回资源元数据。
- 已确认海搜提供搜索与链接检测 API，鉴权调用待验证。

## 首版方向

1. 接入公开搜索 API，完成关键词查询与网盘类型筛选。
2. 统一结果结构，按分享标识去重并保留来源。
3. 增加缓存、超时处理和各来源的失败提示。
4. 按需检测链接，区分有效、失效、需要密码和未知状态。

本项目目前没有可运行的服务；具体来源、接入限制及本轮验证范围见调研文档。
