## 最适合先验证的 API

### 盘搜索：免注册查询

官方文档描述基础地址为 `https://www.pansousuo.com`，查询接口为 `GET /api/search`。支持关键词 `q`、网盘 `pan`、类目 `cat` 与分页 `p` 等参数。

本轮实际请求：

```sh
curl 'https://www.pansousuo.com/api/search?q=Python'
```

实际响应为 JSON：`total=514`，本页 `items` 长度为 24，第一项含非空 `share_url`，并含 `title`、`pan`、`access_code`、`published_at` 等字段。仅核实返回结构，没有访问或检测返回的网盘分享。搜索接口请求过程中曾遇到 DNS 解析失败，随后成功，因此还需要观察稳定性。

`GET /api/stats` 也返回 JSON；其数量和健康率是服务端自报数据，本轮没有独立核验。实际搜索响应使用 `aggregate` 字段，与文档示例不同；接入时以实测结构为准。

文档说明商业用途或大批量调用需先联系站方。首版采用按用户查询调用，避免全量抓取。

### 海搜：有文档的搜索与检测服务

从海搜官网页脚的“开放接口”进入上述 iDataRiver 文档，确认：

- 搜索：`POST https://apiok.us/api/b9d1/search`，参数包括 `query`、`platforms`、`page`、`pageSize`。
- 检测：`POST https://apiok.us/api/b9d1/validate`，具体参数在接入前按文档核实。
- 接口需要在 query string 中提供 `apikey`；响应中的 `code` 用于判断成功，HTTP 200 本身不代表成功。
- 搜索示例含 `shareUrl`、`sharePwd`、`platform`、`title` 等字段。

本轮只确认文档与接口存在，没有注册、购买、获取 key 或实际调用。网页搜索的积分规则与开放接口计费规则应分别读取，不能混用。key 由服务端保存，日志应移除 URL 中的 key。

## 三类来源的用途

1. **网盘搜索站**：盘搜索、海搜、PanSearch、轻搜搜、小鸡窝等，用关键词查询分享索引。
2. **资源文章 / 分类站**：rrdynb 这类站，从条目及详情页提取标题、版本与分享信息，可补充影视信息；单独维护页面规则。
3. **公开分享频道 / 社区**：公开 Telegram 频道等，从帖子识别分享链接和提取码；需要明确频道列表、可访问性和更新时间。

搜索站也会换域名。对自建搜索器而言，多来源、可配置地址、失败隔离和保留来源记录，比只选择“搜索型网站”更能减少单站变化的影响。

## 可复用的聚合后端

[fish2018/pansou](https://github.com/fish2018/pansou) 是可自部署的聚合 API 项目，支持公开频道与插件来源，文档列出 `/api/search`、`/api/health`、`/api/check/links`。它是后端工具，不是一个独立内容索引库；插件存在不代表对应站点当前可用。本轮没有部署或验证插件。

仓库 README 标为 MIT，但项目简介同时包含不用于盈利的说明；若用于商业产品，先确认具体版本的许可与上游来源的使用条件。

## 首版建议

先用盘搜索 API 验证完整查询流程；有 key 后增加海搜；PanSou 作为可选的自部署聚合后端。其余网站保留为补充入口或待验证适配器。

统一结果至少保留：标题、网盘类型、分享 URL、提取码、来源名称、来源页、来源发布时间、采集时间、检测状态、最近检测时间。同一网盘分享 ID 去重时合并来源，不丢失不同来源的描述和提取码。发布时间未知时留空，不用采集时间代替。

每个来源独立设置超时、限流和短期缓存；一个来源失败时返回其他来源的结果，并展示失败来源。链接状态区分有效、失效、需要密码、未知，超时或风控不能直接标为失效。

## 第二轮扩展：已实现并实测

2026-10-15，默认启用来源从盘搜索一个扩展为以下五个：

| 来源 ID | 来源 | 接入范围 |
| --- | --- | --- |
| `pansousuo` | 盘搜索 | 原有公开 JSON 查询与分页 |
| `pansearch` | [PanSearch](https://www.pansearch.me/) | 公开搜索页中的结构化数据；使用页面报告的实际页大小翻页，一条记录的多个分享链接分别提取 |
| `rrdynb` | [人人电影网](https://www.rrdynb.com/index.html) | 公开搜索表单与结果条目的正文；只读取本网站影视条目，每页最多 6 个详情页 |
| `tg_aliyun_4k_movies` | [阿里4K影视公开频道](https://t.me/s/Aliyun_4K_Movies) | 最近公开预览帖子中的关键词匹配 |
| `tg_quark_movies` | [夸克影视公开频道](https://t.me/s/Quark_Movies) | 最近公开预览帖子中的关键词匹配 |

公开频道不是完整历史检索，不把无关的最近帖子当成搜索结果；没有匹配时返回空列表。帖子链接、正文标题与发布时间随分享链接一起保存。重复的网盘分享合并时保留不同原始文章 / 帖子的位置。

人人电影网只从搜索结果区域读取本站影视条目，不抓取侧栏推荐或站外链接；正文中的下载工具链接被排除。详情查询使用共享的整体超时与两路并发，部分详情失败时保留已取得结果。

PanSearch 与 JSON 接口候选的字段研究参考 [PanSou 的公开来源适配器](https://github.com/fish2018/pansou/tree/main/plugin)；本项目直接查询公开页面，并未要求额外部署 PanSou。

本轮未启用的候选包括：趣盘搜旧接口出现 TLS 证书验证失败，其旧网站入口已重定向到另一站点；即刻盘接口连接失败；盘666 返回 403；盘他访问失败；混合盘既有请求格式返回参数错误。这些来源没有被标为可用，也没有关闭 TLS 校验或使用账号绕过访问限制。

配置 `DISABLED_SOURCES` 可以停用某个来源；`TELEGRAM_CHANNELS` 可以替换为最多五个公开频道，设为空则关闭所有频道。海搜和自部署 PanSou 仍作为可选服务保留。
