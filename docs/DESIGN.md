# 盘觅流媒体首页与筛选片库设计

状态：已实现，完成本地验证。日期：2026-10-15。

## 目标与页面职责

把默认入口从资源工作台改为影视发现首页。保留完整的筛选片库与现有多来源网盘搜索、收藏、复制、链接检测和导出能力。电脑与手机使用同一套响应式页面。

| 页面 | 入口与职责 |
| --- | --- |
| 发现 `#home`（默认） | 精选主视觉、本周趋势、最近上映、流媒体平台入口 |
| 片库 `#discover?...` | 地区、平台、类型、时间、自定义日期、最低评分、评分人数、排序、分页 |
| 网盘搜索 `?q=...#search` | 真实多来源资源检索、网盘筛选、打开、复制、检测、收藏 |
| 我的收藏 `#favorites` | 保留当前浏览器中的资源收藏与 JSON 导出 |
| 来源 `#sources` | 查看配置状态与外部入口 |

顶部包含发现、片库、电影、剧集、动漫、综艺与搜索入口。电影等分类进入带预选条件的片库，首页“查看全部”和平台入口同样带入条件。手机保留精简顶部和底部发现、片库、搜索、收藏导航。

## 交互

- 海报与“搜索网盘”直接搜索片名；剧情按钮展示资料弹窗，可用原名搜索。
- 搜索页显示作品上下文和“返回片库/发现”。返回时恢复筛选、已加载分页与滚动位置，不自动重发资源搜索。
- 片库条件编码到 hash 查询中，可分享与刷新恢复，与既有网盘查询参数分开。
- 刷新恢复筛选并重新获取第一页；同一次页面访问中的返回保留分页和滚动，内存最多保留 12 组片库条件。
- 常用类型、地区、平台、时间可见；最低评分、评分人数、自定义日期放进可展开筛选区。手机使用原生折叠面板；已选条件摘要始终可见。
- 明确区分“片库地区”与作品产地。首页平台入口直接打开跨地区片库；地区是可选筛选，不再作为点击平台的前置条件。跨地区模式合并当前支持的八个地区，不暗中切换美国，也不宣称覆盖全球所有地区。
- 修改条件重新查询第一页；追加页去重。日期未填完整时只提示，不提交无效查询；“清空筛选”恢复默认值。
- 搜索来源与网盘筛选维持原有语义。收藏仍是资源收藏，本轮不引入影视想看列表。

## 数据与 API

- 保留 `/api/discover`，新增 `minRating` 最低 TMDb 评分，排序支持评分降序、评分升序、上映日期降序。默认地区不限、最低评分 0，至少 10 人评分优先，不足 10 人的作品排在后一组且仍可加载；点击重新加载收起筛选面板。
- `platform` 指定、`region=all` 时并行查询八个地区的真实平台片库，按作品 ID 合并。每批保留各地区该页的全部作品；返回 `totalType=regional_sum`、`queriedRegions`、`failedRegions` 和部分失败提示，已加载批次统一排序。未指定平台时仍直接查询全球作品。
- 新增 `/api/discover/home`：本周趋势来自 TMDb `trending/all/week`，只接受电影和剧集，过滤人物、成人与未来作品。近期电影和新剧通过已有 discover 查询获得，各分区独立失败；全部失败返回错误，部分失败保留成功分区并显示提示。
- “本周趋势”明确标记为 TMDb 趋势，不宣称为播放量或平台官方榜单。片库评分标记 TMDb，未评分显示暂无评分。
- 扩展作品字段 `backdropUrl`。首页使用宽幅图；无宽幅图退回海报与深色底，无海报使用文字占位。
- 平台入口为片库筛选；不在单部作品上凭空显示平台归属。不将首页推荐解释为网盘资源存在或链接有效。
- 数据未配置、失败、空片单均使用真实空态，不在上线代码中放演示影视数据。凭据只在服务端读取。
- 保留 TMDb 标识、声明和 JustWatch 归属说明。

## 视觉与响应式

采用已确认的炭黑影院风与珊瑚橙强调色：背景 `#0b0f10`、文字 `#f2f0e9`、强调色 `#ef805e`。顶部导航替代侧栏；影视海报 2:3、剧照 16:9。主视觉底部衔接首排片单。

| 宽度 | 布局 |
| --- | --- |
| 320–767px | 顶部精简，主视觉竖向裁切，海报约两列或局部横向片单，筛选折叠，资源单列、操作换行，底部导航适配安全区 |
| 768–1023px | 海报三至四列，筛选换行，导航压缩 |
| ≥1024px | 宽幅主视觉，海报五至六列，资源列表操作同行 |

整页禁止横向溢出；长标题换行；按钮触摸目标约 44px；输入字体至少 16px；键盘焦点可见；不依赖悬停显示必要操作；减少动态效果偏好生效；首屏外图片延迟加载。

## 验收

1. 默认打开为发现，旧搜索链接与旧 `#discover` 链接继续有效。
2. 首页、分类和平台入口均进入正确片库条件，真实影视可搜索网盘。
3. 地区、平台、类型、全部时间、自定义日期、评分上下排序与评分人数实际传到后端。
4. 片库条件可分享、刷新恢复、浏览器前进后退恢复；返回保留分页和滚动。
5. 搜索、复制、收藏与导出继续工作；缺失凭据和上游失败有明确状态。
6. 自动化验证参数、安全字段、趋势过滤、部分失败与旧行为回归；真实本地服务健康检查和浏览器检查响应式布局。

本轮修改现有本地工程，不自动发布远程生产服务。

接口依据：[TMDb 周趋势](https://developer.themoviedb.org/reference/trending-all)、[电影筛选](https://developer.themoviedb.org/reference/discover-movie)、[剧集筛选](https://developer.themoviedb.org/reference/discover-tv)。
